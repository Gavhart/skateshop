# Shopify product copy templates

Paste these into **Shopify Admin → Products → Description**. They stay honest: no invented materials, ratings, or “best in Alaska” claims. Swap the bracketed bits for what’s actually on the item.

Photos still live in Shopify. If a product has no photo or description, the site shows an empty state instead of making one up.

---

## Deck

```
[Brand] [model] skateboard deck.

Width: [e.g. 8.25"]
Shape: [street / popsicle / cruiser — only if you know]

In stock at Hart Boys Skate Shop, Peninsula Center Mall, Suite 48C, Soldotna, AK.

Need a first setup? We can match trucks, wheels, grip, and hardware from what’s on the wall — or start at hartboysskateshop.com/starter.
```

---

## Complete

```
[Brand] [model] complete skateboard — ready to ride once you check hardware and trucks.

What’s included: [deck / trucks / wheels / bearings / grip — list only what this SKU actually ships with]

Size: [width or kids’ size if listed]

Pickup in Soldotna or we ship. Free shipping on orders of $150+.
```

---

## Wheels

```
[Brand] [model] skateboard wheels.

Size: [e.g. 52mm]
Durometer: [e.g. 99a — only if printed on the product]

A set of four unless the title says otherwise. Bearings sold separately unless this product includes them.
```

---

## Apparel (tees, hoodies, hats)

```
[Brand] [item name].

Fit: [true to size / oversized — only if you’ve seen it]
Color: [as listed]

Sizes listed are what’s on this product. Sold out sizes won’t add to cart.

Pickup at Peninsula Center Mall, Suite 48C, or ship from Soldotna.
```

---

## Short fallback (any product)

Use when you only have time for a couple of lines:

```
[Exact product name] from [brand].

Available at Hart Boys Skate Shop in Soldotna, Alaska. Message @hartboysskateshop if you need a measurement before you buy.
```

---

## What not to paste

- Phone numbers or dollar shipping rates that aren’t in shop policy
- Made-up carbon, maple-ply counts, or warranty claims
- Stock photos you don’t have rights to
- “In stock everywhere” if it isn’t
